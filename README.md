# Rotem Azulay | Personal Website

Welcome to the repository for my personal academic portfolio and website. I am a PhD student in the Department of Chemical and Structural Biology at the Weizmann Institute of Science.

## Project Architecture

This website is hosted on GitHub Pages and built using **Jekyll**. 

To maintain a clean separation of concerns, the project is structured as follows:
* **Content:** All text and page content is written in Markdown and lives in `index.md`.
* **Configuration:** Site-wide variables and personal links are stored in `_config.yml`.
* **Design & Layout:** The HTML structure is separated into `_layouts/default.html`, and all custom CSS styling (colors, typography, grid layouts) is located in `assets/css/style.css`.
* **Images:** Visual assets are organized within the `assets/images/` directory.
